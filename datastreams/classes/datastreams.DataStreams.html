getTokenPair

  • getTokenPair(channelId, user): Promise<TokenResponse>

  • Get a token pair for a specific datastream channel

    This method retrieves a token pair that can be used to authenticate and authorize access to the specified datastream channel.

    Parameters

    • channelId: string | number

      The unique identifier or name of the datastream channel

    • user: {
          connectionName?: string;
          userId?: string;
      }

      An object with either userId or connectionName

      • OptionalconnectionName?: string
      • OptionaluserId?: string

    Returns Promise<TokenResponse>

    Response containing the token pair information

    Throws

    CatalystDataStreamError if channelId is invalid or the request fails

    Example

    const datastream = app.datastream();
    const tokenPair = await datastream.getTokenPair("12345", { userId: "user123" }); // Using ID and user ID
    // or
    const tokenPair = await datastream.getTokenPair("my_channel", { connectionName: "connection_name" }); // Using name and connection name
    console.log('token pair::', tokenPair);
