Class PopupManager

Manages the popup-based sign-in and sign-out flows.

Both signInViaPopup and signOutViaPopup open a native browser popup via window.open(). Browsers require this call to originate directly from a trusted user gesture (e.g. a click or keydown event). Calling either method from a timer, resolved Promise, or any other asynchronous context that is not synchronously rooted in user input will cause the popup to be silently blocked by the browser.

Used internally by Authentication. Not exported from web.ts.
